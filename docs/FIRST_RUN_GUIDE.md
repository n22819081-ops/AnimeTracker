# First Run

With no profile, Anime Tracker shows a welcome screen and creates nothing until a choice is confirmed. A clean profile starts with schema 6, zero titles, no Jellyfin scan, no AniList bulk refresh, no scheduled task, and notification Stage 1 Preview Only.

Choose **Create Clean Profile** for a new library. Choose adoption only when the displayed source and target are correct. **Postpone** exits without relocation. Jellyfin roots can then be configured in Settings; all media access remains read-only.
