# Uninstall

Use Windows Installed Apps or the Anime Tracker uninstaller. It removes installed binaries, shortcuts, and registration only. User data under `%LOCALAPPDATA%\Anime Tracker\AnimeTracker` is preserved unconditionally.

The uninstaller does not touch the source project, legacy tracker/database/task, Jellyfin media, configured library roots, Discord data outside the profile, or the separate Storage Checker. No remove-user-data option is included.
