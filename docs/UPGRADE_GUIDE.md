# Upgrade And Reinstall

Close Anime Tracker and run the newer installer. Installer files live separately from `%LOCALAPPDATA%\Anime Tracker\AnimeTracker`, so application replacement preserves databases, settings, credentials, cache, mappings, reviews, history, outbox, baselines, backups, and schedule settings.

This RC has no authentic prior Inno installer, so a real 0.8.0 installer upgrade was not claimed. Same-version and interrupted-install execution could not be completed in the controlled Codex environment because unsigned generated executables were blocked before process creation.
