# Installation

Anime Tracker 1.0.0 supports Windows 10/11 x64. Run the per-user installer and accept the default `%LOCALAPPDATA%\Programs\Anime Tracker` location. No administrator rights, Python installation, source checkout, or virtual environment is required. The installer creates a Start Menu shortcut and offers an unchecked Desktop shortcut.

The build is unsigned, so SmartScreen may display an unknown-publisher warning. Verify `SHA256SUMS.txt` before running it. Do not bypass security software globally.

The portable ZIP contains the same onedir application. Extract the entire `Anime Tracker` folder and run the EXE; user data still goes to `%LOCALAPPDATA%\Anime Tracker\AnimeTracker`.
