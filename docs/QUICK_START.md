# Anime Tracker Quick Start

1. Run `Anime-Tracker-Setup-1.0.0.exe`, or extract the portable ZIP.
2. Launch `Anime Tracker.exe`.
3. Create a clean profile, postpone setup, or explicitly adopt an existing profile.
4. Review the Jellyfin TV and Movies roots. Scans are read-only and never automatic on first run.
5. Add AniList titles and refresh when ready.
6. Run a read-only Jellyfin scan.
7. Review suggested mappings and confirm only the correct season or movie.
8. Use Currently Airing and Finished / Ready to Add to plan additions.
9. Configure Discord only when ready; delivery begins disabled.
10. Install the modern validation task only after deliberately resolving the active legacy task.

Anime Tracker does not download anime, modify Jellyfin, or rename or move media. Existing mappings are never silently replaced, and Season 1 coverage does not satisfy Season 2. Scheduling and Discord are opt-in.
